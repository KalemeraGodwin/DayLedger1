# DayLedger

Executive 24-hour day planner with locked diary reviews and interactive monthly metrics.

## Features
- **24-Hour Continuous Timeline**: Scheduled blocks and available slots spanning 00:00 to 24:00 with 30-minute granularity.
- **Automatic Chronological Cascading**: Adjusting task durations shifts subsequent scheduled tasks automatically.
- **Timeline Integrity Validation**: Automatic detection of overlaps and boundary clipping.
- **Hourly Review & Retrospective Diary**: Dedicated review log debrief lifecycle per slot.
- **Historical Audit Archive**: Past records are frozen with read-only task status while preserving retro review log debrief edits.
- **Executive Performance Reports**: 30-day, 14-day, and 7-day completion velocity, streak tracking, interactive trajectory chart, top accomplished task types, and frequently skipped tasks analysis.
- **Offline & On-Device Storage**: Client-side storage with zero external cloud dependencies.
- **Corporate Styling**: Obsidian Navy (Dark) & Canvas White (Light) executive themes.

## Tech Stack
- React 19, TypeScript
- Vite
- Tailwind CSS
- Lucide React
